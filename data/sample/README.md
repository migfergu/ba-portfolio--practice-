# data/sample/ (committed, synthetic)

**These values are invented.** The files copy the real source layouts (OEWS nat4d columns, Eloundou `occ_level.csv`, O*NET `Job Zones.txt`) so the full pipeline can run without restricted or oversized data.

- Generated by `src/oews_pipeline/sample_data.py` (seed 751). Regenerate with `uv run oews-pipeline make-sample`. A test checks that the committed files match the generator byte for byte.
- 20 real SOC codes × 10 real 4-digit industries × May 2021–2025, about 70% cell density.
- Defects are injected on purpose so every validation path fires: BLS `**` / `*` / `#` symbols, comma-formatted numbers, aggregate rows, an exact duplicate (2022), a conflicting duplicate and a blank title (2023), a malformed SOC and lowercase headers (2024), negative employment (2025), a non-numeric value and 4-character NAICS codes (2021), and exposure rows with an out-of-range rating and a malformed O*NET code.

Do not interpret any number derived from these files.
