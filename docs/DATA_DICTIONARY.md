# Data Dictionary

Database: `data/processed/oews_genai.db` (SQLite). DDL lives in `src/oews_pipeline/schema.py`.
Key column: **PK** primary key, **FK** foreign key, **CK** has a CHECK constraint.

## dim_occupation — one row per detailed 2018 SOC occupation in the panel

| Field | Type | Key | Source | Business rule |
|---|---|---|---|---|
| soc_code | TEXT | PK, CK | OEWS `OCC_CODE` | Must match `NN-NNNN`. Only `O_GROUP = detailed` rows enter the panel. |
| occ_title | TEXT | | OEWS `OCC_TITLE` | Title from the **latest** year the code appears, because BLS occasionally revises titles. |
| major_group | TEXT | CK | Derived | First two SOC digits + `-0000` (e.g., `13-0000`). |
| focal_role | TEXT | CK | `config/sources.toml` | `analyst` = 13-2051 Financial and Investment Analysts; `clerk_contrast` = 43-3031 Bookkeeping, Accounting, and Auditing Clerks; otherwise NULL. Drives the A3 finance contrast. |
| soc_vintage | TEXT | | Constant | `2018 SOC`. OEWS May 2021 onward uses the 2018 SOC throughout, so no SOC crosswalk is needed within 2021–2025. |

## dim_industry — one row per 4-digit NAICS industry

| Field | Type | Key | Source | Business rule |
|---|---|---|---|---|
| naics_code | TEXT | PK, CK | OEWS `NAICS` | BLS's 6-character form (e.g., `523100` = 4-digit 5231). 4-character inputs are right-padded with zeros. Only `I_GROUP = 4-digit` rows enter the panel. |
| naics_title | TEXT | | OEWS `NAICS_TITLE` | Latest-year title. |
| industry_level | TEXT | | OEWS `I_GROUP` | `4-digit` (configurable in `sources.toml`). |
| naics_sector | TEXT | CK | Derived | First two digits; supports sector-level summaries and clustering checks. |

## dim_year — one row per May reference year

| Field | Type | Key | Source | Business rule |
|---|---|---|---|---|
| year | INTEGER | PK, CK | Config | May reference year, 2021–2025. |
| period | TEXT | CK | Derived | `pre` for 2021–2022; `post` for 2023+. ChatGPT launched Nov 30, 2022, so May 2023 is the first post period. |
| post | INTEGER | CK | Derived | 1 if `year >= post_start_year` (2023). |
| post_delayed | INTEGER | CK | Derived | 1 if `year >= 2024`. This is the delayed-post robustness check from A3. |
| reference_month | TEXT | | Constant | `May`. |

## occupation_exposure — GenAI exposure per SOC (0 or 1 row per occupation)

| Field | Type | Key | Source | Business rule |
|---|---|---|---|---|
| soc_code | TEXT | PK, FK → dim_occupation | Eloundou `O*NET-SOC Code` | O*NET-SOC 2019 codes (`NN-NNNN.NN`) are truncated to 6-digit 2018 SOC. The O*NET-SOC 2019 taxonomy is built on the 2018 SOC, so this mapping is exact at the 6-digit level. |
| exposure_alpha | REAL | CK [0,1] | `dv_rating_alpha` | E1: share of tasks where an LLM alone cuts time by at least 50%. Unweighted mean across O*NET codes within the SOC. |
| exposure_beta | REAL | CK [0,1] | `dv_rating_beta` | E1 + 0.5·E2. |
| exposure_gamma | REAL | CK [0,1] | `dv_rating_gamma` | E1 + E2: exposed directly **or** with complementary software. |
| exposure_main | REAL | CK [0,1] | Configured column | The measure named by `exposure_measure` in `sources.toml`. Default `dv_rating_gamma`, matching the A3 definition. |
| exposure_z | REAL | | Derived | (exposure_main − mean) / SD across SOCs **matched to the OEWS panel** (unweighted, sample SD). One unit = 1 SD, so β reads as the effect of a 1-SD exposure difference. |
| measure | TEXT | | Config | Which column `exposure_main` holds. |
| n_onet_codes | INTEGER | CK ≥ 1 | Derived | How many O*NET codes were averaged into the SOC. |
| source_version | TEXT | | Manifest | Release label. The file hash is in `source_file_log`. |

Exposure rows for SOCs not in the OEWS panel are counted and dropped (they would violate the FK). Panel SOCs without a score stay in the panel with NULL exposure and `emp_model_ready = 0`.

## fact_oews_estimate — one row per occupation × industry × year

| Field | Type | Key | Source | Business rule |
|---|---|---|---|---|
| soc_code | TEXT | PK, FK → dim_occupation | `OCC_CODE` | |
| naics_code | TEXT | PK, FK → dim_industry | `NAICS` | |

| wage_suppressed | INTEGER | CK {0,1} | Derived | 1 if BLS withheld the wage. |

## Audit tables

**etl_run** — one row per pipeline execution: `run_id` PK; `started_at` and `finished_at` (UTC ISO-8601); `status` ∈ {running, succeeded, failed}; `source_mode` ∈ {sample, raw}; `facts_inserted`, `facts_updated`, `facts_unchanged`, `rows_rejected`; `error_message` (failed runs only).

**source_file_log** — PK (`run_id`, `source_name`): `file_name`, `version`, `sha256` (full hash of the file read), `size_bytes`, `rows_read`. Lets an authorized user confirm they loaded the same files.

**rejected_record** — `reject_id` PK, `run_id` FK, `source_name`, `record_key` (`soc|naics|year` or O*NET code), `reason_code`, `detail`, `raw_record` (JSON of original cell values).

| reason_code | Trigger | Action |
|---|---|---|
| INVALID_SOC | `OCC_CODE` not `NN-NNNN` | Row quarantined |
| INVALID_NAICS | NAICS not 6 digits after padding | Row quarantined |
| INVALID_ONET | O*NET code not `NN-NNNN.NN` | Row quarantined |
| NON_NUMERIC | Numeric field is neither a number nor a documented BLS symbol | Row quarantined |
| RANGE | Value outside its valid range (negative employment, rating outside [0,1], Job Zone outside 1–5) | Row quarantined |
| MISSING_REQUIRED | Blank code or title | Row quarantined |
| DUPLICATE_EXACT | Identical source row repeated in the file (a file-level repeat of a published estimate, not evidence of a duplicate transaction; OEWS has no transaction IDs) | Extra copy quarantined; one kept |
| DUPLICATE_CONFLICT | Same key, different values | All copies quarantined |

## View: v_analysis_panel

Joins the fact table to all dimensions (LEFT JOIN to exposure and preparation). It adds `exposure_x_post = exposure_z × post`, plus `emp_model_ready` and `wage_model_ready`, which are 1 when the outcome and exposure are both non-NULL. Logs are taken in Python at estimation time, because SQLite's `ln()` is not available in every build.
